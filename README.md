# POOLROOMS

Игра-исследование про затопленные лиминальные пространства: кафель, вода, свет.
Плюс редактор уровней.

## Что открывать

Два самодостаточных файла — просто двойной клик, без сервера и без интернета:

| Файл | Что это |
|---|---|
| `game.html` | Игра |
| `editor.html` | Редактор уровней |

Внутрь каждого зашит весь код, включая three.js. Файлы можно копировать куда угодно
и отправлять кому угодно — они самодостаточны. Нужен браузер с WebGL2
(Chrome / Edge / Firefox / Safari 16+).

## Управление в игре

| Клавиши | Действие |
|---|---|
| мышь | обзор (захват указателя) |
| держать `ЛКМ` и вести | обзор, если браузер не отдал захват мыши |
| стрелки | обзор с клавиатуры |
| `W` `A` `S` `D` | движение |
| `Shift` | бег / быстрое плавание |
| `Space` | прыжок · всплыть |
| `Ctrl` или `C` | присесть · нырнуть |
| `V` | свободный полёт (отладка) |
| `Esc` | пауза |
| `F1` | скрыть HUD |
| `F2` | скриншот в PNG |

Обзор работает тремя способами, потому что захват мыши браузер иногда не даёт
(например, если запросить его сразу после выхода). Если захвата нет — появится
подсказка, и камера будет слушаться перетаскивания и стрелок. На тач-экране
обзор — одним пальцем.

Персонаж сам переключается между ходьбой, бродом по мелководью и плаванием
в зависимости от глубины. Под водой есть запас воздуха — на нуле выталкивает наверх.

## Редактор уровней

Слева — инструменты, в центре — план сверху, справа — живой 3D-предпросмотр
на том же движке, что и игра.

| | |
|---|---|
| `ЛКМ` / `ПКМ` | рисовать / стирать |
| `Shift` + тянуть | прямоугольник |
| `Ctrl` + `ЛКМ` | заливка области |
| `Alt` или `СКМ` | панорама, колесо — зум |
| `1`…`8` | инструменты |
| `[` `]` | размер кисти |
| `X` | повернуть объект |
| `2×клик` | перенести камеру превью в точку |
| `WASD` / `QE` | летать камерой превью |
| `Tab` | превью: изнутри ↔ вид сверху со срезом |
| `R` | пересобрать 3D |
| `Ctrl+S` | сохранить в .json |
| `Ctrl+Z` / `Ctrl+Shift+Z` | отменить / вернуть |
| `Ctrl+S` | сохранить в .json |

**Инструменты:** комната, стена, высота пола, высота потолка, материал, объект,
точка спавна, пипетка.

**Объекты:** колонны (квадратные и круглые), арки, дверные проёмы, окна-щели,
лестницы, поручни в воду, ограждения, растения, лампы, таблички, стулья, скамьи,
мячи, сливы, горки, неоновые полосы, свет в полу, потолочные споты, кафельные
сферы, души, неон-вывески.

Арки, двери и окна ставятся **в стену** (в клетку типа «стена») — они сами
прорезают проём и строят софит. Остальные объекты — внутрь комнаты.

**Атмосферы:** стерильный день, золотой закат, мшистая тишина, подвал с лампами,
ночная бирюза, затопленный неон, тёмный кафель, оранжерея. Каждая задаёт солнце,
туман, цвет и поглощение воды, цветокоррекцию.

Уровни сохраняются в `.json`, либо «В список игры» — тогда они появятся в меню
игры (через localStorage). Кнопка **▶ Играть** запускает текущий уровень сразу.
Черновик автосохраняется в браузере.

## Как устроена графика

Всё процедурное — ни одной внешней текстуры и ни одного звукового файла.

**Вода** (`src/core/water.js`)
- планарное отражение через зеркальную камеру с отсечением по плоскости
- преломление в отдельный буфер с картой глубины
- поглощение по закону Бугера–Ламберта–Бера с разными коэффициентами по RGB
  плюс однократное рассеяние и мутность
- нормали ряби считаются аналитически: 6 направленных волн + капиллярный шум
- френель, блик GGX, пена по урезу воды
- взгляд снизу: окно Снелла через `refract()` и полное внутреннее отражение
- LOD: вдали рябь слабеет, а блик размывается, иначе поверхность кипит бликами

**Каустики** (`src/core/caustics.js`)
- рёбра деформированной диаграммы Вороного с периодическим хэшем, поэтому
  текстура бесшовно тайлится; рендерится один раз за кадр в 512²
- на дне — затухание с глубиной; на стенах над водой — отражённые «зайчики»

**Кафель** (`src/core/materials.js`, `shaderlib.js`)
- полностью процедурный: сетка швов со сглаживанием по `fwidth`, фаска по краям
  плиток, индивидуальная вариация каждой плитки, налёт в углах, вертикальные
  подтёки, тёмная полоса по ватерлинии, мокрый глянец у воды
- фильтрация по LOD: вдали деталь сходится к среднему — нет муара

**Свет** (`src/core/post.js`, `engine.js`)
- объёмные лучи: трассировка луча через карту теней солнца с фазовой функцией
  Хеньи–Гринштейна и джиттером
- подводный слой: экспоненциальное поглощение по глубине, дисперсия, взвесь,
  колебание изображения
- bloom собственной реализации (цепочка downsample/upsample), ACES, грейдинг
  lift/gain/контраст/насыщенность, виньетка, зерно, FXAA
- IBL из процедурной панорамы неба через PMREM
- запечённая в вершины окклюзия: контактные тени в углах и под потолком

**Звук** (`src/game/audio.js`) — WebAudio: розовый шум для гула зала, полосовой
фильтр с LFO для плеска, свёрточная реверберация под кафельный зал, капли по
случайному расписанию, шаги и всплески, глухой фильтр под водой.

## Что сделано для производительности

Профилирование показало, что кадр упирался не в филлрейт, а в число вызовов
отрисовки: сцена рисуется трижды (отражение, преломление, основной проход),
и каждое растение давало полтора десятка отдельных мешей.

| Оптимизация | Эффект |
|---|---|
| Пропы сливаются в общие меши по материалам | 138 мешей → 23, сцена −69 % |
| Вода: пропуск RT, когда поверхности нет в кадре | в сухих комнатах вода бесплатна |
| Вода: под водой RT не нужны (только небо и каустики) | затопленные уровни −2 прохода |
| Вода: отражение обновляется через кадр | −½ стоимости отражения |
| Объёмный свет считается в половинном разрешении | рейтрейсинг вчетверо дешевле |
| Карта теней перерисовывается по порогу движения | геометрический проход не каждый кадр |
| Шум в шейдере кафеля — по ветвям и в 3 октавы | грязь считается только там, где видна |
| Выбор 8 источников без аллокаций, раз в 3 кадра | нет мусора в куче на каждом кадре |
| Адаптивное разрешение под целевой FPS | плавность на слабом железе |

Итог на тестовой сцене (1600×900): **6.5 мс → 2.3 мс** на кадр в зале с водой,
**0.7 мс** в комнатах без воды. Картинка не изменилась.

В редакторе план разнесён на два слоя: тяжёлый статический кэшируется в
offscreen-канвас, поверх рисуется только курсор. На уровне 160×160 наведение
мыши подешевело с 4.1 мс до 0.05 мс. Статистика по клеткам пересчитывается
после правок, а не на каждое движение мыши; 3D-предпросмотр в простое
обновляется реже и полностью останавливается на скрытой вкладке.

## Сборка

Исходники — в `src/`. Чтобы пересобрать HTML после правок:

```bash
node build.mjs
```

Отдельно и без минификации (удобно для отладки):

```bash
node build.mjs --dev --only=game
```

Зависимости ставятся один раз: `npm install`.

## Структура

```
game.html          собранная игра (открывать этот файл)
editor.html        собранный редактор
build.mjs          сборка: esbuild -> инлайн в HTML
src/
  core/
    engine.js      сцена, свет, тени, цикл рендера
    water.js       вода: отражение, преломление, поглощение
    caustics.js    процедурные каустики в render target
    materials.js   кафель, бетон, металл, листва, неон, вода душа
    shaderlib.js   общие GLSL-куски: шум, вороной, плитка, ACES
    post.js        объёмный свет, подводный слой, bloom, грейдинг, FXAA
    level.js       формат уровня, RLE-сериализация, коллизии, демо-уровни
    builder.js     сетка уровня -> геометрия (стены, арки, окна, объекты)
    env.js         пресеты атмосферы + процедурное небо
    quality.js     профили качества
  game/
    main.js        меню, HUD, игровой цикл
    player.js      ходьба / брод / плавание, коллизии, покачивание
    audio.js       процедурная звуковая среда
  editor/
    main.js        редактор: план, инструменты, 3D-предпросмотр
```
